AQUASENTINEL IA

Este es el repositorio oficial del proyecto AQUASENTINEL donde encontraras el archivo final y ejecutable del proyecto tanto en forma de simulador como de archivo funcional para datos ya existentes ademas de nuestro Paper Investigativo con todas las evidencias y justificaciones  del por para y porque decidimos realizar este trabajo

-Cosas que debes saber:
  
  Para el correcto funcionamiento del reporte de IA es necesario que el ordenador donde se ejecute el programa tenga instalado LM Studio (https://lmstudio.ai/) y el modelo  Qwen2.5 Coder 3B Instruct (qwen2.5-coder-3b-instruct) descargado en el mismo
  
  En el caso del simulador y el archivo que genera el reporte solicitan de vscode (https://code.visualstudio.com/) con las dependencias de python recomendadas por el sistema



  -En el desarrollo de el simulador se hicieron consultas a documentacion de godot ( para la implementacion del simulador y su conexion al programa) ,blender (modelado del ecosistema) y python (Desarrollo del programa y conexiones con LM studio y godot) con el fin de lograr una version competente y adecuada a las especificaciones y reomendaciones dadas por los supervisores.

  ¡Esperamos que este proyecto sea de tu agrado y muchas gracias por pasarte por aqui!
